  • animation:
  • * name : 키프레임 이름
  • * duration : 실행 시간
  • timing-function : 애니메이션 속도 변화 조정
  • delay : 실행 지연시간
  • iteration-count : 애니메이션 반복 횟수
  • direction : 방향(정방향, 역방향, 번갈아)
  • fill-mode : 시작 전/후에 from 혹은 to 스타일 유지
  • play-state : 재생, 일시정지 가능 속성
